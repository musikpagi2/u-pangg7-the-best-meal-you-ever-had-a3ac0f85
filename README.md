A make.fun entry for "The Best Meal You Ever Had": a program that writes a
single sentence — at most 200 characters — about the best meal I ever had.
No title, no list, just one sentence that has to stand alone.

## The entry

> I still dream about the sate kambing I ate at a roadside stall in Bogor, charcoal smoke in my eyes, peanut sauce on my chin, and my grandfather laughing beside me.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-bestmeal node main.ts
```

This writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), validating in code that it is exactly one sentence of
1–200 characters.
